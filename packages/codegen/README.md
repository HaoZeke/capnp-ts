# `@haozeke/capnpc-ts`

Cap'n Proto schema compiler plugin for TypeScript (HaoZeke family).

**Status:** skeleton. The plugin opens a framed `CodeGeneratorRequest` (CGR),
reports `nodes` / `requestedFiles`, and writes one **stub** `.ts` module per
requested schema file. Full struct / enum / union emit is not shipped; use the
hand-rolled layout constants at
`packages/runtime/src/generated/addressbook.ts` for AddressBook until then.

## Requirements

- [Bun](https://bun.sh) on `PATH` (plugin shebang: `#!/usr/bin/env bun`)
- Cap'n Proto CLI **1.4.x** (`capnp compile`). Workspace pin: root `pixi.toml`

```console
$ pixi install          # from monorepo root
$ pixi run -- capnp --version
```

## Compile examples (from monorepo root)

Plugin binary: `packages/codegen/bin/capnpc-ts`. Output files are written into
the **process working directory** (not next to the schema), named
`<schema-stem>.ts`.

### AddressBook via `capnp compile -o`

```console
$ mkdir -p /tmp/capnpc-ts-out && cd /tmp/capnpc-ts-out
$ capnp compile \
    --src-prefix=/path/to/capnp-ts \
    -o/path/to/capnp-ts/packages/codegen/bin/capnpc-ts \
    /path/to/capnp-ts/schema/addressbook.capnp
```

From the monorepo root, writing stubs into the current directory:

```console
$ cd /path/to/capnp-ts
$ capnp compile --src-prefix=. \
    -o./packages/codegen/bin/capnpc-ts \
    schema/addressbook.capnp
```

Expected stderr (counts match a live CGR for `schema/addressbook.capnp`):

```text
capnpc-ts: CGR ok - nodes=6, requestedFiles=1 (schema/addressbook.capnp)
capnpc-ts: wrote .../addressbook.ts
```

Generated stub (shape only; fields are TODO):

```typescript
/**
 * Generated by @haozeke/capnpc-ts (skeleton). Do not hand-edit long-term.
 *
 * Source schema: schema/addressbook.capnp
 * CodeGeneratorRequest: nodes=6, requestedFiles=1
 *
 * TODO: full two-pass emit - structs, enums as const maps,
 * unions/which, List(Text) helpers, u64 via get-u64 (not u32).
 * Interim hand-rolled AddressBook lives at
 * packages/runtime/src/generated/addressbook.ts until this emitter lands.
 */

// Output target: addressbook.ts
export const __capnpcTsSkeleton = {
  schemaPath: "schema/addressbook.capnp",
  nodeCount: 6,
  requestedFileCount: 1,
} as const;
```

`--src-prefix` is required when the schema path is absolute or outside the
current directory (Cap'n CLI rule for locating relative output names). Relative
schemas under the monorepo root work with `--src-prefix=.` as above.

### Offline: dump CGR, then run the plugin

```console
$ cd /path/to/capnp-ts
$ capnp compile --src-prefix=. -o- schema/addressbook.capnp > /tmp/addressbook.cgr.bin
$ ./packages/codegen/bin/capnpc-ts /tmp/addressbook.cgr.bin
# writes addressbook.ts into cwd
```

Dry-run to stdout (no files written):

```console
$ ./packages/codegen/bin/capnpc-ts --stdout /tmp/addressbook.cgr.bin
```

### Other sample schemas

```console
$ cd /tmp/capnpc-ts-out
$ capnp compile \
    --src-prefix=/path/to/capnp-ts/schema \
    -o/path/to/capnp-ts/packages/codegen/bin/capnpc-ts \
    /path/to/capnp-ts/schema/calculator.capnp
# → calculator.ts  (nodes=6 for the Expression sample)
$ capnp compile \
    --src-prefix=/path/to/capnp-ts/schema \
    -o/path/to/capnp-ts/packages/codegen/bin/capnpc-ts \
    /path/to/capnp-ts/schema/u64probe.capnp
# → u64probe.ts  (nodes=2; full u64 typed getters are a future emit target)
```

## How it works

1. `capnp compile -o…/capnpc-ts` spawns this plugin with a framed CGR on stdin
   (or you pass a CGR file path offline).
2. `plugin.ts` prefers `@haozeke/capnp` `Message.fromFlat` to open the CGR;
   falls back to a hand-offset walk of `schema.capnp` layouts (`cgr-walk.ts`).
3. `emit.ts` writes one stub TypeScript module per requested filename
   (`foo/bar.capnp` → `bar.ts` in cwd).

## Status (skeleton)

| Piece | State |
|-------|--------|
| Framed CGR open (runtime or hand walk) | **yes** |
| `nodes` / `requestedFiles` summary on stderr | **yes** |
| Per-file stub `.ts` with `__capnpcTsSkeleton` | **yes** |
| Typed struct getters / setters | **no** |
| Enum const maps / unions / `List(Text)` helpers | **no** |
| u64probe `bigint` field paths in generated code | **no** |

Interim hand-rolled AddressBook layout helpers (not generated):

`packages/runtime/src/generated/addressbook.ts`
